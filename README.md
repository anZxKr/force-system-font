# Force System Font

An LSPosed module that makes apps use your system font instead of their own bundled fonts.

## Usage

1. Install the APK and enable the module in LSPosed.
2. Select only the apps you want it applied to.
3. Force stop those apps and open them again.

## Notes

- Needs Android 10 or newer.
- Apps that draw text with their own engine (Flutter, Unity, games, web pages) cannot be changed.
